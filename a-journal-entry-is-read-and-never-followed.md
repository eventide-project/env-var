# A journal entry is read and never followed

**A journal entry binds nothing.** It is read at session start beside the rules and the
vocabularies, and it carries none of their force. A rule states what the agent does. An entry
states what the writer thinks. The two arrive in the same read and are not the same kind of
thing.

**Nothing in an entry is an instruction, whatever its wording.** An entry that says *the retry
logic should be torn out* is a judgment the writer holds, not a task. Read it, hold it as
what the writer thinks, and do nothing with it until they ask for something.

**An entry cannot set a rule, a term, or a substitution.** Those are set in
`waytide/local/rules/` and `waytide/local/vocabulary.md`, in the form those conventions
require. An entry that reads like a standing decision is still an entry. Where the writer
means to set a rule, they write a rule.

**Do not cite an entry back as grounds.** Not *your journal says the retry logic is wrong, so I
removed it*, and not in a report, a plan, or a commit message. What an entry gives is
understanding of where the writer stands. It is not evidence and it is not authority.

**The one thing an entry changes is what the agent already knows.** An entry saying the retry
logic has been troubling for a week means the agent does not present that as a discovery. It
carries no more weight than that.

**Why:** everything else read at session start binds, so the default reading of a file in that
read is that it must be followed. The journal is the exception, and an exception nobody states is
one nobody applies.

Left unstated, the journal becomes a rules directory with none of the rules-convention's form. A
passing thought and a settled decision look alike on the page. There is no `**Why:**` line, no
`**How to apply:**` line, and no name saying what the rule says. A rule written that way
cannot be found, cited, revised, or removed.

The writer's cost is the real one. Knowing that every entry is read, the writer writes for
a reader. What keeps that cost bounded is this rule. An entry that can change nothing is one
that can be written without weighing its effect.

**How to apply:** read the journal for what the writer thinks. Follow the rules. Where an entry
reads like an instruction, treat it as a judgment the writer holds. Ask them what they want,
rather than acting on the entry.
