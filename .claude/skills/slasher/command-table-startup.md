| Command | Description |
|---|---|
| `/slasher help, /help` | Print the help of every Slasher command |
| `/commands, /;` | Print the list of Slasher commands |
| `/recent, /?` | Brief summary of recent work, and what's next. |
| `/current, /', /c` | Lists the current items, features, and experiments. |

The other commands are `/next`, `/proceed`, `/next?`, `/item`, `/feature`, `/features`, `/experiment`, `/experiments`, `/process`, `/log`, `/decision`, `/note`, `/notes`, `/record`, `/records`, `/journal`, `/private`, `/brainstorm`, `/test`, `/push`, `/p`, `/commit-and-push`, `/cp`, `/projects`, `/release`, `/package`, `/packages`, `/language`, `/pros-and-cons`, `/ask-again`, `/aa`, `/estimate-confidence`, `/unattended`, `/shortcuts`, `/sc`, and `/load`.

Type /help for all of Slasher's help, or /<command> help for one command's.
